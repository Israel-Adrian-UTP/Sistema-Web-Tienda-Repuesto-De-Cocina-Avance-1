# Sistema Web - Tienda de Repuestos de Cocina (Avance 1)

Proyecto web desarrollado como entrega parcial (**Avance 1**) para la asignatura de **Taller de Programación Web** en la **Universidad Tecnológica del Perú (UTP)**.

---

## Descripción del Proyecto

La plataforma tiene como objetivo organizar y digitalizar el catálogo de una tienda especializada en repuestos y accesorios de cocina (como mangueras, reguladores, quemadores, perillas y tapas de marcas como Mabe, Bosch, Sole e Indurama). Mediante una estructura web clara y un módulo de administración proyectado, busca agilizar la búsqueda de piezas compatibles y facilitar la gestión del inventario en tiempo real.

---
